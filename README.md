# 🧠 Deep Learning for Medical Infection Prediction

This project explores the use of deep learning models (CNN + LSTM) for predicting infection and ischemia conditions using medical data.

## 🚀 Overview
The goal of this project is to build and evaluate multiple deep learning architectures for medical diagnosis, combining spatial feature extraction with temporal modeling.

## 🧠 Models Implemented
- CNN (DenseNet, EfficientNet, MobileNet)
- CNN + LSTM hybrid models
- Bayesian Optimization for hyperparameter tuning

## 📊 Key Features
- Multi-model experimentation across architectures
- Performance evaluation using metrics (accuracy, loss, etc.)
- Comparative analysis of models

## ⚙️ Tech Stack
- Python
- TensorFlow / PyTorch
- Jupyter Notebooks
- NumPy, Pandas

## 📈 Results
- CNN + LSTM models showed improved performance over standalone CNNs
- Bayesian optimization improved model tuning efficiency

## 💡 Learnings
- Combining spatial + temporal models improves prediction performance
- Hyperparameter tuning plays a critical role in medical ML tasks
